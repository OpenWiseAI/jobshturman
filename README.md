# JobShturman

Агент в Claude Code, Cowork или Codex ведёт поиск работы по методике: анкета, факты и резюме, сбор вакансий с hh.ru, Telegram и LinkedIn, отклики, учёт ответов и подготовка к встречам. **Данные кандидата остаются на компьютере.** Методика выдаётся по ключу доступа.

> Это дом рантайма JobShturman для версии 1.0 (в организации OpenWiseAI). Здесь — открытый код: установщик, программа `jbs`/`hrs`, сборщик вакансий, локальный MCP-сервер и навык. Методика сюда не входит — она приватная и приходит по ключу с сервера ключей.

## Что нужно

- macOS или Windows и Claude Code / Cowork или Codex.
- Ключ доступа из письма после оплаты.

## Установка

Одна команда в терминале (ставит `uv`, программу `jbs` из последнего выпуска и подключает её к агентам):

```bash
curl -fsSL https://raw.githubusercontent.com/OpenWiseAI/jobshturman/main/install.sh | sh
```

Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/OpenWiseAI/jobshturman/main/install.ps1 | iex
```

После установки полностью перезапустите агента: новый MCP-сервер виден только в новой сессии.

## Начало работы

1. Напишите агенту «JobShturman».
2. Вставьте ключ доступа из письма. Ключ хранится в связке ключей macOS (на Windows/Linux — в защищённом файле), агенту его повторять не нужно.
3. Напишите «начни этап 0» — агент проведёт анкету и покажет карту запроса.

## Где данные

macOS: `~/Library/Application Support/HRShturman`, Windows: `%APPDATA%\HRShturman`, Linux: `~/.local/share/hrshturman`. Там анкета, факты, резюме, вакансии и отклики. Методика лежит только в зашифрованном виде. Серверу ключей уходят лишь ключ и случайный id установки.
